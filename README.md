# resume_generator

## RAG implementation.
Input text (Description), pdf, image or URL (Media) than create Latex resume, which should cotains at least:
1. User registration (SSO).
2. Previous Version & Now Versions compare (Image).
3. Update keyword and recent learned knowledge
    * Write Skills description
    * Analysis Next Project idea, list what should I learn.
    * Career Path Recommendation.
    * List relevant topic or speach recommandation.

### Required
* FastAPI
* Typescript
* PostgresSQL
* JWT
* Nginx
* Langchain, Langgraph
* Docker
* Deploy on AWS
* Redis
* SocketIO for processing progress.
* Database migration.

### Bonus:
* Payuni API for pricing.
* Electron for APP.
* Celery Server.
* Pytest For Uploading test
* Locut for uploading stress test
